# Legacy CIFAR-10 classifier

This directory preserves the original 3x32x32 CIFAR-10 classifier, its HLS IP,
Vivado artifacts, ARM proof-of-concept, laptop scripts, and original planning
documents. It is not part of the active EdgeDet-Z20 build.

The unrelated auto-accept VSIX and zero-byte CIFAR archive were intentionally
removed during migration. The old documentation and generated outputs are
retained only to reproduce and compare the original baseline.
